 # 🌍 CountryLens – Instant Country Search

A modern, fast, and beautiful **Next.js 14+ App Router project** that lets users instantly search and explore countries using real-time API data.

Built with performance-first UX, smooth animations, and clean UI design.

---

## 🚀 Features

- ⚡ Instant live search (Google-style UX)
- 🌍 Real-time country data (REST Countries API)
- 🧠 Smart ranking & relevance sorting
- 🎯 Debounced input for performance
- 💾 Local caching for faster results
- 🎨 Glassmorphism UI with smooth animations
- 📱 Fully responsive design
- 🧩 Splash screen experience
- 🖼️ Country flags with optimized rendering

---

## 🛠️ Tech Stack

- **Next.js 14+ (App Router)**
- **React 18**
- **TypeScript**
- **Tailwind CSS**
- **REST Countries API**
- **Geist Font (Vercel)**
